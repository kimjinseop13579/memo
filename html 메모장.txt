<div> </div> : division(분할) 영역을 나눌때사용함, 개발자가 자유롭게 이용할수있도록 안에 가지고있는것이 없음
                    자유롭게 세부내용을 수정할수있음
 - <header></header>
 - <footer></footer>
 - <main></main>
 -- 세가지 모두 div와 기능은 같음 사용할때 내용을 분리하기 편하라고 나눠놓은 것임

<nav> : navigation 네비게이션의 줄임말 
<p> : 문단을 나타내는 용어
<br> : break 브레이크의 줄임말 줄바꿀때 사용됨 enter와 같은역할
<hr> : horizontal rule 의 줄임말 수평선을 나타내는 용어 선이 만들어짐
<ul> : unorder순서가 없는 리스트 번호가 안붙음
<ol> : order list 의 줄임말 순서가있는 리스트 번호가 자동으로 붙음
<dl> : description list 의 줄임말 설명을 표현할때 사용
<li> : list item 의 줄임말 목록(리스트)에 들어가는 글자나 이미지를 나타냄
     리스트를 수직이 아니라 수평으로 만들려면 style을 줘야함

<dt> : description term 의 줄임말용어 를 나타냄
<dd> : 설명을 나타냄
 - 커피
   - 아메리카노
   - 라떼
   - 콜드브루
   음료
   - 자몽티
   - 레몬티
 -- 여기서 커피와 음료는 dt 안에있는 아메리카노, 라떼, 자몽티 등등은 dd로 표현됨

<a> : anchor 의 줄임말 링크 포인트 라는뜻으로 사용됨 하이퍼링크
 - <a href="http://www.naver.com">네이버 이동</a> 와같이 적으면 저장후 화면에 "네이버 이동" 을 누르면 
   해당 링크로 이동함

표를 만드는 줄임말
 - <tr> : table row 표에서 행을 나타냄
 - <td> : table data 표에서 칸(열) 을 나타냄
 - <th> : tabel header 테이블의 머리말
 
<img> : 이미지를 보여주기위한 태그
 - src="http://picsum.photos/500/400" 더미이미지를 보여주는 사이트

입력이 가능한 테그
 <form> 입력테그 들의 폼, 입력값 전달 기능 수행
 <input> 입력할수있는 태그
 <label> label - input 태그의 명칭 , 상호 호환
 <button> 버튼
 <textarea> 장문을 작성할수있는 크기조정이되는 입력창
